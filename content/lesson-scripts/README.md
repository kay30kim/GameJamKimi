# 나이별 언어 학습 대본

각 주제 JSON에는 3·4·5·6세 × 한국어·영어의 독립된 대본 8편이 있습니다. 검토 페이지는 이 원고에서 생성합니다. 게임의 생성형 대사나 카메라 코드와는 아직 연결하지 않았습니다.

```sh
npm run scripts:build
npm run scripts:check
```

검토 페이지: `/lesson-scripts.html`. 나이·언어·주제를 선택하거나, ‘나이별 비교’로 같은 주제의 네 나이를 한 화면에서 비교합니다. 인쇄는 현재 보이는 대본만 포함합니다. 이전 주소의 `#ko-kindness` 같은 링크는 한국어 3세 해당 주제로 연결합니다.

## 원고 기준

- 3세: 짧은 한마디, 눈앞의 행동 하나, 구체적인 감정 이름. 한 표현을 충분히 듣고 따라 할 수 있게 합니다.
- 4세: 짧은 부탁과 대답, 행동 전후의 감정. ‘어떻게 달라졌는지’를 캐릭터가 말합니다.
- 5세: 행동 때문에 마음이 달라진 이유, 표현을 다시 사용하는 대화.
- 6세: 서로 다른 입장과 이유를 말하고, 새 상황에서 같은 표현을 사용합니다.

나이는 편집 기준이며 능력 평가가 아닙니다. 보호자가 아이에게 맞는 버전을 골라 읽고, 듣기만 하거나 손짓으로 답해도 됩니다.

모든 버전은 **상황 속 표현 → 뜻의 명시적 설명 → 선택 결과에서 사용 → 앨리스의 함께 말하기 → 새 상황에서 다시 사용**을 포함합니다. 영어 대본에서도 `“도와줄까?” means “Can I help?” in English.`처럼 뜻을 설명합니다. 단순히 두 언어를 나열하는 것으로 끝내지 않습니다.

## 선택과 감정

네 장면 중 세 번째 장면에 두 선택과 각 결과를 모두 씁니다. 친절은 ‘누가 돕느냐’만 바꾸지 않습니다. 도움을 놓쳤을 때 친구가 느끼는 속상함·외로움과 이를 알아차리고 다시 도울 기회를 보여 줍니다. 비난·벌·친구 관계 박탈로 몰아가지 않습니다. 마지막에는 도움받은 캐릭터가 무엇 때문에 기분이 좋아졌는지 말하고, 앨리스도 친구가 기뻐하는 모습을 보고 느낀 기쁨을 말합니다. 두 경로가 합쳐질 때에는 두 경로에서 실제로 일어난 일만 언급합니다.

**몸의 경계·원치 않는 접촉·음식 거절·쉬거나 지켜보기는 ‘나쁜 선택’이 아닙니다.** 이 경우 거절 때문에 상대가 속상하다는 식으로 압박하지 않습니다. 몸의 경계 주제에서는 두 선택 모두 존중받고, 동의는 언제든 바꿀 수 있습니다. 먹을 양·배고픔·배부름을 무시하거나 억지로 먹게 하지 않습니다.

## 촬영 원칙 — 런타임 연결 시 필수

사용자 요구: **말하는 동안 해당 캐릭터의 양쪽 눈·코·입이 모두 보여야 합니다. 뒤돌아 말하면 안 됩니다.**

1. 화자가 바뀌면 음성 시작 전에 화자의 가슴 위 정면 또는 약한 3/4 구도를 확보합니다. 완전한 옆얼굴도 피합니다.
2. 발화가 끝날 때까지 얼굴을 유지합니다. 상대에게 시선을 주되 머리 방향과 카메라를 조정해 이목구비를 가리지 않습니다.
3. 뒤돌아 걷기·회전은 대사 전에 끝내거나 대사 뒤로 옮깁니다. 이동 중 대사가 꼭 필요하면 카메라가 앞에서 따라갑니다.
4. 소품·상대 배우·벤치 등이 얼굴을 가리지 않습니다. 손과 소품을 보여 주는 구도에서도 화자의 얼굴은 보이게 합니다.
5. 동의 대사 → 접촉 시작, ‘그만’ 대사 → 즉시 접촉 종료, 건네기 → 받은 뒤 감사의 순서를 지킵니다. 실제 음성 시작·종료와 연결해 검증해야 합니다.

현재 검토 페이지는 각 장면에 이 촬영 지침을 명시합니다. **이 문서가 카메라 구현을 대신하지는 않습니다.** 실제 게임에서 등이나 가려진 얼굴이 보이는 문제는 런타임 카메라·배우 방향 검증과 함께 별도로 수정해야 합니다.

## 파일 구조

- `*.json`: 주제별 원고. `phrase`는 선택 언어의 핵심 표현, `meaning`은 다른 언어의 같은 뜻입니다. 각 버전은 완전한 대사·행동·분기 결과·새 상황 질문을 갖습니다.
- `review.css`: 읽기·비교·인쇄 화면의 스타일.
- `../../scripts/build-lesson-scripts.mjs`: 80편의 누락·중복·표현·따라 말하기·분기를 검사하고 단일 HTML을 생성합니다.
- `../../public/lesson-scripts.html`: 배포 및 로컬 검토용 결과물. 직접 수정하지 말고 JSON을 고친 뒤 다시 생성합니다.

자동 검사는 문학적 자연스러움이나 교육 효과를 증명하지 않습니다. 감정의 인과관계, 번역의 정확성, 나이별 대사 차이, 선택 후 소품의 주인과 배우 자세는 원고 검토와 실제 재생으로 확인해야 합니다.
